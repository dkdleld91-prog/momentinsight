# 모먼트 인사이트 쿠팡 순위 확인 확장 — 대표용 안내

C 30일 순위 화면의 **'지금 확인'** 버튼을 쓰려면, 대표님이 평소 쓰시는 맥 크롬에 이 확장을 한 번 설치해야 합니다.
아래 순서대로만 하시면 됩니다. 메뉴 이름은 크롬 영어 표기와 한국어 표기를 함께 적었습니다.
한국어 표기 중 [추정]이라고 적은 것은 실제 화면과 조금 다를 수 있으니, 다르면 영어 이름과 위치로 찾아 주세요.

## 1. 이 확장이 하는 일과 하지 않는 일

하는 일
- 대표님이 카드의 '지금 확인'을 **누를 때만** 움직입니다. 예약·자동 반복·한꺼번에 확인은 없습니다(알람 권한도 없습니다).
- 누르면 먼저 **빈 새 시크릿 창**을 하나 엽니다(이때는 쿠팡에 아무 요청도 하지 않습니다). 정말 시크릿 창인지, 다른 시크릿 창이
  없는지 본 뒤에 우리 서버(insight.momentlabs.co.kr)에 "이 요청이 지금 검색해도 되는 요청인지" 확인받습니다.
  서버가 검색 사이 3분·하루 30번·09~19시·그날 중지를 **서버 시계로** 판단합니다. 서버가 허락하지 않으면 쿠팡을 열지 않고 창을 닫습니다.
- 허락을 받으면 그 창에서 쿠팡 검색 1쪽을 한 번 열어 상품 목록만 읽은 뒤 창을 닫습니다(약 15~30초).
- 쿠팡 차단 화면(HTTP 403·429·503, '사용권한이 없습니다', 로그인 화면 등으로 보냄)이 보이면 그 즉시 서버에 알려
  **그날의 '지금 확인'을 모두 멈춥니다.** 다음 날 09시에 저절로 다시 됩니다(멈춤을 푸는 버튼은 없습니다).
  알림이 실패하면 몇 초 뒤 두 번 더 보내고, 그래도 안 되면 다음에 관리자 화면을 열거나 다시 누를 때 보냅니다(그 사이 이 크롬은 새 검색을 하지 않습니다).

하지 않는 일
- 상품을 누르지 않고, 글을 입력하지 않습니다. 스크롤은 자동 수집기와 같은 만큼(1,400픽셀씩 8번, 필요하면 2번 더)만 합니다.
- 차단을 피하는 어떤 일도 하지 않습니다(자동화 표시 숨기기, 브라우저 정보 바꾸기, 주소(IP) 바꾸기, 쿠키 넣기 없음).
- 대표님이 평소 여는 쿠팡 창·탭에는 아무것도 하지 않습니다. 확장이 직접 연 시크릿 창에서만 읽습니다.
- 쿠키·방문 기록·비밀번호를 저장하지 않습니다.

## 2. 설치 전에 확인할 것

- **크롬에서만** 씁니다(엣지·웨일에는 설치하지 마세요).
- 대표님이 **평소 쓰시는 맥 크롬 프로필**에 설치합니다.
- **네이버 수집용 크롬(데스크탑 Profile 3)과 맥 대기 수집 프로필(Profile 5)에는 절대 설치하지 마세요.**
  확인 방법: 주소창에 `chrome://version` 입력 → '프로필 경로(Profile Path)' 끝이 `Profile 3`·`Profile 5` 가 아니어야 합니다.
- 이 맥의 크롬은 N30 대기 수집(Profile 5)과 같은 크롬 앱입니다. 그쪽 점검이 크롬을 다시 켜는 순간과 겹치면
  확인이 중간에 끊길 수 있습니다(그 1번은 오늘 횟수에 셉니다). 끊기면 몇 분 뒤 다시 누르시면 됩니다.

## 3. 설치 순서

1. 관리자 → C 30일 순위 → 맨 아래 **총관리자 패널** 펼치기 → **'지금 확인(내 크롬)'** 구역 → **확장 내려받기(zip)**.
   기대: 다운로드 폴더에 `mi-coupang-check-1.0.0.zip` 이 생깁니다.
2. zip 을 두 번 눌러 풀면 **`mi-coupang-check`** 폴더가 생깁니다(폴더 이름에 버전이 없습니다).
3. Finder → 이동 → 홈(⌘⇧H)에서 **`모먼트인사이트`** 폴더를 새로 만들고, 2번의 `mi-coupang-check` 폴더를 그 안으로 옮깁니다.
   - 문서·다운로드·데스크탑 폴더에는 두지 마세요. 맥이 그 폴더들을 앱마다 따로 허락받게 해서, 크롬을 다시 켤 때
     확장을 못 읽을 수 있습니다[추정]. 다운로드 폴더를 비우면 확장이 사라지기도 합니다.
4. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **Developer mode(개발자 모드)** 를 켭니다.
   기대: 왼쪽 위에 버튼 3개가 나타납니다.
   - **개발자 모드는 계속 켜 두세요.** 끄면 이 확장이 바로 꺼지고 '지금 확인'이 멈춥니다.
5. **Load unpacked(압축해제된 확장 프로그램 로드)** → 3번의 `모먼트인사이트/mi-coupang-check` 폴더(안에 `manifest.json` 이 바로 보이는 폴더)를 고르고 열기.
   기대: '모먼트 인사이트 쿠팡 순위 확인 1.0.0' 카드가 생깁니다.
6. 그 카드의 **Details(세부정보)** →
   - **Allow in Incognito(시크릿 모드에서 허용)** 를 켭니다. 기대: 스위치가 파란색.
   - **Site access(사이트 액세스)** 는 바꾸지 마세요. **On click(클릭 시)[추정]** 으로 바뀌어 있으면 확장이 시작하지 않습니다.
7. 같은 `chrome://extensions` 화면에서 **다른 확장들의 '시크릿 모드에서 허용'은 꺼 두세요**(다른 확장이 시크릿 창의 쿠팡 화면을 바꿀 수 있습니다).
8. C 30일 화면을 새로고침 → 패널의 **확장 상태 다시 보기**.
   기대: "설치됨 v1.0.0 · 시크릿 허용 켜짐". 이렇게 보이면 확장 ID 도 맞는 것입니다(따로 대조하지 않아도 됩니다).
   안 보이면 카드에 적힌 ID(32글자)를 개발 담당에게 알려 주세요.
9. 패널의 **지금 확인 켜기** → 확인. 기대: 추적 카드마다 '지금 확인' 버튼, 상태 줄 "지금 확인: 오늘 0/30번 …".

## 4. 쓰는 법

- 누르기 전에 **열려 있는 시크릿 창을 모두 닫아 주세요.** 시크릿 창이 하나라도 있으면 확장이 시작하지 않습니다
  (시크릿 창끼리는 쿠키를 함께 쓰기 때문입니다).
- 누르면 새 시크릿 창이 열리고(서버 확인을 받은 뒤 앞으로 옵니다) 쿠팡 검색 화면이 보이고, 아래로 몇 번 내려간 뒤 저절로 닫힙니다(약 15~30초).
- 그동안 **열린 창을 직접 닫거나, 누르거나, 내리거나, 다른 창으로 가리지 마세요.** 창은 확장이 저절로 닫습니다. 관리자 화면도 닫지 마세요.
  (창이 가려지거나 내려가면 목록을 끝까지 못 읽었을 수 있어 그 번 순위는 기록하지 않습니다.)
  (관리자 화면이 닫혀도 결과는 확장이 들고 있다가 다음에 화면을 열 때 서버로 다시 보냅니다. 차단이었다면 그날 중지는 이미 걸립니다.)
- 결과는 상태 줄에 "확인 완료: … 일반 N위"처럼 나오고, 카드의 '현재'·오늘 칸이 바뀝니다.
  다음 확인은 3분 뒤부터 됩니다(모든 사람·모든 설치를 합쳐 서버가 셉니다).

## 5. 시작하지 않았거나 실패했을 때

| 화면에 보이는 사유 | 쿠팡 검색 | 할 일 |
|---|---|---|
| 확장이 없거나 꺼져 있음 | 안 함 | `chrome://extensions` 에서 개발자 모드·확장 스위치가 켜져 있는지, 카드에 오류가 없는지 확인 |
| 시크릿 모드에서 허용이 꺼져 있음 | 안 함 | 3장 6번 |
| 사이트 액세스가 막혀 있음 | 안 함 | 3장 6번(사이트 액세스를 '클릭 시'가 아니게) |
| 다른 시크릿 창이 열려 있음 | 안 함 | 모든 시크릿 창을 닫고 다시 누르기 |
| 시크릿 창을 열었지만 확장이 다룰 수 없음 | 안 함 | 열린 빈 시크릿 창을 직접 닫고, 시크릿 모드에서 허용 켜기 |
| 시크릿 창을 열지 못함 | 안 함 | 크롬 설정에서 시크릿 모드가 막혀 있을 수 있음 → 개발 담당에게 알리기 |
| 쿠팡 검색 전에 시크릿 창이 닫힘 | 안 함 | 확장이 연 창은 직접 닫지 않기 |
| 서버가 허락하지 않음(간격·횟수·시간·오늘 중지·다시 로그인 등) | 안 함 | 화면의 사유대로(시간이 지나면 됨, 로그인이 풀렸으면 다시 로그인). 화면은 로그인돼 있는데 '서버가 로그인 정보를 받지 못했다'고 나오면 그 문구를 개발 담당에게 알리기 |
| 서버에 연결하지 못함 | 안 함 | 인터넷 연결 확인 후 다시 |
| 확장이 방금 확인함 / 다른 확인 중 | 안 함 | 잠시 뒤 다시 |
| 오늘 차단으로 보이는 화면이 있었음 | 안 함 | 오늘은 끝. 다음 날 09시부터 다시 됨 |
| 확인 중에 시크릿 창이 닫힘 / 창을 눌러 다른 쪽으로 감 | 함 | 다음에는 창을 건드리지 않기(닫히기 전에 차단 화면·로그인 화면이 보였다면 차단으로 보고 그날 멈춥니다) |
| 창이 가려지거나 내려가 목록을 끝까지 읽지 못함 | 함 | 다음에는 창을 가리지 않기(그 번 순위는 기록하지 않음) |
| 45초 안에 다 열리지 않음 / 불러오지 못함 / 2분 상한 | 함 | 인터넷 상태를 보고 3분 뒤 다시 |
| 쿠팡이 검색이 아닌 곳(로그인 화면 등)으로 보냄 | 함 | 차단으로 보고 그날 멈춥니다(대표 결정 D1) |
| 확장이 연 시크릿 창이 남아 있을 수 있음 | — | 열린 시크릿 창을 직접 닫기 |

확장이 빈 창 검사를 마치고 서버 확인을 받은 뒤라면, 쿠팡 검색을 못 했어도 그 1번은 오늘 횟수에 셉니다
(화면에 '이번 1번은 오늘 횟수에 들어갔고'라고 나옵니다). 그 전에 멈춘 경우(창을 못 엶·다른 시크릿 창 등)는 세지 않습니다.

## 6. 업데이트

1. 패널에서 새 zip 을 내려받습니다.
2. Finder 에서 `모먼트인사이트/mi-coupang-check` 폴더를 휴지통으로 옮깁니다.
3. 새 zip 을 풀어 생긴 `mi-coupang-check` 폴더를 같은 `모먼트인사이트` 폴더에 넣습니다(이름이 같아야 합니다).
4. `chrome://extensions` → 이 확장 카드의 새로고침(↻).
5. 패널 '확장 상태 다시 보기' → 새 버전이 보이면 끝입니다. 확장 ID 는 바뀌지 않습니다.
   - 카드를 **Remove(삭제)** 했다가 다시 Load unpacked 했다면, '시크릿 모드에서 허용'을 다시 켜야 할 수 있습니다[추정].

## 7. 급히 멈추기·지우기

- 가장 빠른 방법: 총관리자 패널 **'지금 확인 끄기'**(확인 창 없이 바로). 서버가 모든 요청을 거절하고 버튼이 사라집니다.
- 이 크롬에서만 멈추기: `chrome://extensions` → 이 확장 카드의 스위치 끄기(개발자 모드를 끄는 것도 같은 효과).
- 지우기: `chrome://extensions` → 카드 **Remove(삭제)** → 홈의 `모먼트인사이트/mi-coupang-check` 폴더도 휴지통으로.

## 8. 개발 메모(대표님은 읽지 않으셔도 됩니다)

- 권한: `scripting`(확장이 연 탭에 읽기 함수 넣기)·`storage`(아래 값) + 호스트 `https://www.coupang.com/*`(읽기)·`https://insight.momentlabs.co.kr/*`(서버 확인).
  `incognito: "spanning"`(관리자 창의 메시지를 받은 같은 프로세스가 시크릿 창을 다뤄야 함). 관리자 화면 연결은 `https://insight.momentlabs.co.kr/admin*` 만.
  알람·탭·요청 가로채기·쿠키·디버거·프록시·내용 스크립트 권한은 없습니다(테스트로 막음).
- 서버 요청은 GET 2가지뿐입니다(세션 게이트가 확장 출처의 POST 를 막으므로): `?view=manual-verify&claimId=…`(빈 시크릿 창 검사 뒤,
  쿠팡 주소를 넣기 직전), `?view=manual-stop&claimId=…&reason=…`(차단 신호를 본 순간. 실패하면 같은 실행 안에서 3초·10초 뒤에 다시,
  그래도 실패하면 다음 hello·누름 때 다시). 요청 토큰은 `x-mi-coupang-claim-token` 머리글로만 보냅니다.
- 차단 신호(HTTP 상태·차단 문구·주소)는 load 확인(1초마다)과 불러온 직후의 짧은 읽기 1번에서도 남깁니다. 사람이 첫 읽기 전에
  창을 닫거나 45초·120초 상한에 걸려도 그 값으로 결과를 만들고, 권한 밖(www.coupang.com 밖)으로 보내져 읽지 못한 것을 봤으면
  `page_unreadable`(D1)로 그날 멈춥니다. 측정 중 주소 바뀜은 측정 시작 때 탭 주소와 비교합니다: 경로가 바뀌거나 쿼리 값이 이름을
  가리지 않고(q·정렬·쪽 번호·목록 크기·로켓배송·브랜드·가격대·분류·`filter` 등) 하나라도 생기거나·없어지거나·바뀌면 이동입니다.
  같은 값의 다른 모양(빈 값 = 값 없음, `page=01` = `page=1`, `sorter=scoreDesc`·`page=1` = 값 없음, 값의 순서, 주소 끝 `#…`)은 이동이 아닙니다.
  값은 trim 하지 않습니다(앞뒤 공백도 다른 값이고, 공백만 있는 값도 값이 있는 것 — 쪽 함수와 확장이 같은 규칙인지 시험이 봅니다).
  무시하는 이름은 쿠팡 추적 값으로 근거가 확인된 것뿐이고 지금은 없습니다(저장소·수집기 기록에 근거가 없어 `channel`·`traceId` 도 넣지 않음.
  `sourceType`·`rank`·`searchRank`·`itemsCount` 는 상품 링크의 값이라 검색 주소와 무관). 그래서 쿠팡이 측정 중에 주소에 스스로 값을 붙이면
  그 확인은 `user_navigated`(순위 기록 안 함·그날 중지 아님)로 끝납니다 — 틀린 순위 대신 '기록 안 함'으로 끝나는 안전한 쪽 실패입니다.
  쿼리만 바뀌어 이렇게 끝나면 확장 결과 `page.changedParams` 에 생기거나·없어지거나·바뀐 쿼리 이름을 싣고(이름만·값 없음, `q` 가 있으면 맨 앞,
  이름마다 40자·10개까지), 서버는 그 회차 `final_path` 에 `/np/search?이름&이름`(인코딩, 80자 안, 넘치면 끝에 `&…`)으로 남깁니다(회차 표에
  오류 세부 칸이 없어 기존 칸을 씀, 마이그레이션 없음). 화면은 '확인 중에 검색 창 주소가 바뀌어 순위를 기록하지 않았습니다(바뀐 값: 이름들).
  창 안을 누르지 않았다면 알려 주세요.'라고 보입니다. 경로나 `q` 가 바뀐 이동은 전처럼 '창 안에서 다른 쪽으로 옮겨졌습니다'입니다.
- 창을 열기 전에 보낸 쪽(`origin`·주소 `/admin`·최상위 프레임의 탭)과 check 모양(요청 id·토큰·검색어)을 모두 봅니다. 어긋나면 창 0개.
