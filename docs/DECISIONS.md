### 40개 단위 페이지 환산을 폐기한다

- 네이버 쇼핑 검색 API의 `start` 순서는 공식 API 결과 배열 순번일 뿐, 사용자 쇼핑 화면의 페이지·위치와 동일하다는 보장이 없다.
- API 순번을 40으로 나눠 `5페이지 8위`처럼 표시하던 로직은 제거한다.
- 서버는 `rankBasis=official_api_result_order`, `webPageVerified=false`, `page=null`, `position=null`을 반환한다.

### 상품 일치와 화면 노출을 구분한다

- 판매자 상품 URL의 상품ID와 API 결과 링크의 판매자 상품ID가 같으면 `상품 ID 일치`로 표시한다.
- 이 일치는 실제 쇼핑 화면의 동일 위치 노출을 증명하지 않으므로 `정확 상품 순위`라고 표현하지 않는다.
- 관리자·광고주·SEO·30일 추적·공유 이미지에서 같은 용어를 사용한다.

### 실제 화면 순위는 별도 수집 근거가 있을 때만 제공한다

- 네이버 실화면 자동 접근이 제한되면 페이지 순위를 추정하거나 성공 처리하지 않는다.
- 향후 실제 쇼핑 화면 순위 수집기를 연결할 경우 API 순번과 화면 순위를 별도 필드·별도 출처로 저장한다.
- 네이버 Developers 쇼핑 검색 API의 2026-07-31 종료 전에 NAVER API HUB 이관 여부와 대체 수집 방식을 확정한다.

## 2026-07-14 · 상품 30일 대표 순위는 정확 상품과 관련 원부 중 높은 값 사용

### 단건 일치와 30일 대표값을 분리한다

- 단건 상품 조회의 대상 ID와 상품 ID 일치 판정은 기존처럼 입력한 판매자 상품ID에만 고정한다.
- 30일 추적 스냅샷은 정확 상품과 검증된 관련 원부의 공식 API 순번을 비교해 숫자가 더 낮은 쪽을 대표 순위로 저장한다.
- 관련 원부가 더 높으면 `related_catalog`, 정확 상품이 높거나 같으면 `exact_product`를 선택 근거로 저장한다.
- 이 기준은 네이버 쇼핑 실화면 순위가 아니라 공식 API 결과 배열 내 대표 순번이다.

### 출처를 숨기지 않는다

- 현재 순위에는 `원부` 또는 `상품` 출처를 함께 표시하고 메시지에는 선택 근거를 문장으로 남긴다.
- 오전·오후 기록 칸에는 `원부` 또는 `상품`을 표시해 날짜별 기준 변경을 확인할 수 있게 한다.
- 과거 스냅샷에는 원부 순번 원본이 없으므로 임의 소급 계산하지 않고 다음 갱신부터 새 기준을 적용한다.

## 2026-07-14 · 네이버 상품 대표 순위와 페이지 표기 재확정

### 원부와 정확 상품 중 더 높은 오가닉 노출을 대표값으로 사용한다

- 단건 조회와 30일 추적의 대표값을 분리하지 않는다.
- 검증된 관련 원부와 판매자 상품ID가 일치한 정확 상품 중 숫자가 더 낮은 오가닉 순위를 대표 `rank`로 사용한다.
- 대표값이 원부면 상품 형태는 `원부형`, 정확 상품이 더 높거나 동률이면 정확 상품의 형태를 사용한다.
- 대표값이 원부여도 입력 상품ID와 원본 URL을 덮어쓰지 않고 정확 상품 카드를 별도 보존한다.

### 페이지는 40개 보기 오가닉 기준으로 표시한다

- `page=ceil(rank/40)`, `position=((rank-1)%40)+1`을 서버와 두 역할 화면, 새 30일 스냅샷에 동일 적용한다.
- `공식 API N번째` 문구는 사용자 화면에서 제거하고 `N위·N페이지 N위`로 표시한다.
- 광고 데이터가 없으므로 광고 카드 수나 광고 포함 화면 슬롯은 계산하지 않는다.

### 실제 화면과 자동 수집 한계를 함께 기록한다

- 로그인 네이버 가격비교에서 `전동칫솔` 원부 34위·정확 상품 168위, 정확 상품 5페이지 오가닉 8위와 판매자 상품ID `12649811979`를 확인했다.
- 독립 Playwright 서버 요청은 HTTP 418로 차단되어 실화면 자동 수집을 운영 경로로 가장하지 않는다.

## 2026-07-14 · 상품 순위 추적은 광고 완전 제외 오가닉만 저장

### 광고 판정은 명시 필드와 비오가닉 타입으로 제한한다

- `isAdProduct`, `adId`, sponsored/paid 계열과 `supersaving`·`brand_ad` 삽입 타입은 순위 계산 전에 제외한다.
- `adcr` 링크는 정상 오가닉 상품에도 존재하므로 URL만으로 광고를 판정하지 않는다.
- 네이버 실화면의 `product` 순번과 별도 삽입 타입을 구분하고 `product` 오가닉 순번만 페이지·순위 기준으로 사용한다.

### 추적과 저장 단계에서 다시 검증한다

- 대표 원부·정확 상품 선택 전에 광고 후보를 제거하고, 광고 후보만 남으면 순위 없음으로 처리한다.
- 수동 갱신·자동 크론은 같은 `runTrackerCheck` 경로를 사용하며 새 스냅샷의 대표 항목과 `top_items`도 오가닉만 저장한다.
- 새 스냅샷에는 `rankPolicy=organic_only`, `adExcluded=true`, 제외 개수를 기록한다. 과거 기록은 근거 없이 소급 변경하지 않는다.
