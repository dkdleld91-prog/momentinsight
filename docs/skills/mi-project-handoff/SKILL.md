# 프로젝트 인수인계 (목표가 끊기지 않게)

인수인계서: `~/.config/momentinsight/HANDOFF.md` — 이 프로젝트의 단일 기준 문서다.

## 시작할 때 (무엇이든 하기 전에)
1. 인수인계서를 끝까지 읽는다. 특히 1장(최종 목표)·2장(현재 위치)·3장(다음 할 일)·6장(마지막 로그).
2. 받은 요청이 **어느 목표(A 멈추지 않는 수집 / B 틀리지 않는 순위 / C 대표가 직접 운영)의 어느 단계**에 해당하는지 한 줄로 정한다. 어디에도 안 맞으면 대표에게 그 사실을 말한다.
3. 2장의 상태가 지금도 사실인지 가볍게 검증한다(라이브 release, 진단 도구). 다르면 문서를 먼저 고친다.
4. 대표에게 첫 보고를 할 때 "지금 목표 ○의 ○단계를 이어받았다"를 한 문장으로 밝힌다.

## 다른 에이전트에게 맡길 때
맡기는 지시문의 맨 위에 넣는다: ① 최종 목표(해당 항목) ② 현재 단계와 이미 끝난 것 ③ 이번에 끝내야 할 것과 완료 기준 ④ 하면 안 되는 것 ⑤ 결과를 돌려줄 형식. 에이전트는 최대 1명, 토큰이 실제로 줄 때만 쓴다.

## 끝내거나 멈출 때 (대화가 끊기기 전에 반드시)
1. 2장 표를 현재 사실로 고친다(날짜·시각 포함).
2. 3장을 다시 쓴다: 끝난 항목은 지우고, 남은 일을 **다음 사람이 바로 실행할 수 있는 수준**(브랜치·커밋·파일·명령)으로 적는다.
3. 4장(대표 작업·결정 대기)을 갱신한다.
4. 6장 맨 위에 로그를 추가한다: 한 일 / 확인된 것 / 미확인인 것 / 다음 사람이 시작할 곳. 5줄 이내. 오래된 로그는 10개만 남긴다.
5. 미확인을 확인된 것처럼 적지 않는다. 검사를 안 돌렸으면 안 돌렸다고 적는다.

## 중간에도 갱신하는 시점
배포·마이그레이션 적용·장애 발생과 복구·대표의 결정(승인/보류/거절)·목표나 우선순위 변경. 목표(1장)는 대표가 바꿀 때만 바꾼다.
