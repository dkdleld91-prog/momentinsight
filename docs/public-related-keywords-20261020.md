# 비로그인 연관 키워드 조회

상태: 구현·사전 검수 통과. 운영 배포 및 운영 비로그인 검수 전에는 완료로 보고하지 않는다.

## 승인 범위와 보존

- 같은 모먼트인사이트 도메인 안의 공개 연관어 화면, 최대 50개 실제 검색광고 연관어와 기존 단일 시트 XLSX를 제공한다. 부족한 결과는 채우지 않는다.
- 기존 로그인 키워드 조회·연관어 인증 게이트·순위추적 런타임·일정·DB 스키마·광고주 데이터는 유지한다.
- 기존 보호 운영 문서는 자동 수정하지 않는다. `work:autosave`는 해당 보호 문서를 덮어쓰므로 실행하지 않고 이 전용 명세에 진행·검수·배포 근거를 기록한다. 원본 dirty 체크아웃은 건드리지 않고 기존 격리 작업트리를 사용한다.
- 사용자 승인: 실제 검수 후 커밋·운영 배포. 새 유료 자원·환경변수·마이그레이션은 추가하지 않는다.

## 공개 경계

- 공개 경로만 별도 노출하며 기존 세션 게이트 allowlist는 넓히지 않는다.
- 검색광고 공개 지표만 반환한다. 쿠키·대행사 코드·역할 머리글과 무관하며 카테고리 근거·저장 순위·광고주 데이터는 읽거나 반환하지 않는다.
- 순수 SearchAd source factory를 공유하되 공개·로그인의 캐시와 동시 작업 및 제한 예산은 분리한다.
- XLSX는 현재 표시된 실제 결과를 브라우저에서 생성하며 다운로드로 추가 API 요청을 만들지 않는다.

## 호출 제한

- IP별 1분 5회 및 1시간 30회. 모든 조회 요청(캐시 적중 포함)에 적용한다.
- 공개 전체 조회 요청은 1시간 100회. 공개 신규 SearchAd 호출은 전체 1분 6회이며 캐시 적중·동시 중복 요청은 신규 호출 예산을 쓰지 않는다.
- 기존 서비스 전용 `consume_code_login_rate_limit(text,integer,integer)`를 별도 `public-related:v1` 해시 이름으로 재사용한다. 로그인 버킷과 공유하지 않는다. 운영 catalog SELECT로 서명·허용 범위·실행 권한을 확인했고 함수/스키마 변경은 없다.
- 제한 응답은 429와 Retry-After, 제한기 장애·형식 불명은 503으로 차단한다. 서버 키와 원본 IP는 응답·브라우저·로그에 노출하지 않는다.
- 인스턴스 캐시는 최대 256개·24시간이며 공개 source 장애/429는 실패 캐시나 무한 재시도를 만들지 않는다.

## 필수 검수

1. 공개 무인증 50개·소수·0개·제한 경계 및 실패 차단, 외부/DB 호출 없는 RED 회귀.
2. 기존 로그인 관련어·키워드·역할 격리·순위 보호 잠금, 전체 check:release 및 독립 P0/P1 검토.
3. 로컬 실제 공개 화면의 조회·엑셀과 기존 로그인 화면 대조. 모킹 결과와 실제 데이터 증거는 구분.
4. 승인된 정확 커밋 1회 push 및 Git Production READY 확인. 중복 CLI 배포 없음.
5. 운영 비로그인 실제 조회·XLSX 전 행 대조·429 제한 확인, 기존 로그인 기능 및 무인증 private API 401 보존 확인.

- 대상 검사 83/83, 현대 Supabase 서버 키 호환 추가 후 공개 대상 24/24. 제한 키는 기존 SUPABASE_SECRET_KEY를 우선하며 현대 키는 apikey만 전송한다. 민감값을 출력하거나 새 키/환경변수를 만들지 않았다.
- 최종 전체 check:release: core 3248/3248, Place 59/59, Shopping 104/104(합계3411/3411), 실패·skip 0. Production auth18/18, public build33파일, 순위 보호 잠금·역할·스코프·CSP 검사 통과.
- 공개 실제 HTML PC/모바일 fixture 12검사, XLSX 4개(50/50/25/5행) 대조 통과. 기존 관리자/광고주 fixture 8검사·XLSX10개 통과. fixture와 실제 운영 증거는 구분한다.
- 같은 Production 프로젝트의 기존 로컬 서버 설정을 메모리에서만 로드한 loopback 실검수에서 에어프라이어50행/XLSX50행, 스테나5행/XLSX5행 전 값·순서 일치, 스테나퓨어304는0행·다운로드 비활성을 확인했다. 브라우저에 서버 키는 전달하지 않았다.

- 독립 P0/P1 blocker0, Git diff-check 통과. 원본 보호9개 파일의 SHA256/모드 보존. 기존 private 세션 게이트·순위 런타임·DB 함수/마이그레이션·vercel.json·admin inline·XLSX writer 변경 없음.
- Git 밖 상세 증거: .codex-deployments/public-related-20261020/. 운영 승격 증거는 배포 후 기록한다.
